## **When editing Code**
After making any changes to a unit test file, ALWAYS run the test to verify that it passes. This is a critical step that must not be skipped. The test should be run immediately after making changes to ensure that the changes did not introduce any regressions or new issues. This applies to all test files in the project, but especially to those in the test/game/phases/ directory.
