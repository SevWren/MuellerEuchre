### Foundational Principles

1.  **SSOT (Single Source of Truth):** This is a broader application of DRY, applied to data and information. It dictates that there should be one canonical source for any given piece of data or configuration in a system. All other parts of the system refer to this primary source.

2. KISS (Keep It Simple, Stupid)

3. YAGNI (You Ain't Gonna Need It)

4. SoC (Separation of Concerns)

5. SRP (Single Responsibility Principle)

6. DIP (Dependency Inversion Principle)
