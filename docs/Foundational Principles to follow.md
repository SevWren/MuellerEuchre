### Foundational Principles

1.  **DRY (Don't Repeat Yourself):** This principle states that every piece of knowledge must have a single, unambiguous, authoritative representation within a system. In practice, this means avoiding the duplication of code by abstracting it into functions or classes.

2.  **SSOT (Single Source of Truth):** This is a broader application of DRY, applied to data and information. It dictates that there should be one canonical source for any given piece of data or configuration in a system. All other parts of the system refer to this primary source.

3. KISS (Keep It Simple, Stupid)

4. YAGNI (You Ain't Gonna Need It)

5. SoC (Separation of Concerns)

6. SRP (Single Responsibility Principle)

7. DIP (Dependency Inversion Principle)
